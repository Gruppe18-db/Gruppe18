# Githubregeln
- Nie direkt auf main arbeiten
- Für jede Aufgabe ein eigener Branch erstellen
- Branch immer von main erstellen
- Regelmäßig committen (kleine Änderungen)
- Änderungen immer pushen
- Zusammenarbeit auf einem Branch ist möglich (absprechen!, gleichzeitig bz. Parallel sollte man auf einem Branch nicht arbeiten) -> u.a. auf die Startseite bezogen
- Verständliche Commit-Nachrichten schreiben
- Vor dem Merge immer ein Pull Request (optional und immer in Absprache)
- Branch nach dem Merge löschen (optional und immer in Absprache)
- Branch so benennen: feature/[feature name]
- Bei Unsicherheiten melden/fragen!
